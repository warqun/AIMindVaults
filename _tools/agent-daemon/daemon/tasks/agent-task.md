# 지시서 — `_AGENT_TASKS` 작업 1건 처리 (Claude · Codex 공용)

> `Run-AgentTask.ps1 -Task agent-task -Agent <claude|codex>` 가 부르는 지시서.
> 사람이 없는 상태에서 실행된다. **물어볼 상대가 없다는 전제로 판단한다.**
> 인박스(`_INBOX.md`) 쪽 지시서는 [[inbox-task]] — 그쪽은 폰에서 던진 한 줄을 처리한다.

## 0. 어느 파일인가

환경변수 **`AIMV_TASK_FILE`** 에 멀티볼트 루트 기준 상대경로가 들어 있다.
그 파일을 읽는 것이 첫 동작이다.

```bash
echo $AIMV_TASK_FILE      # 예: _AGENT_TASKS/todo/20260909_타일색_재검토.md
```

- 환경변수가 비어 있으면 **아무것도 하지 않고 끝낸다.** 대상 없이 일을 지어내지 않는다
- 파일의 frontmatter (`agent` · `model` · `effort`) 는 **러너가 이미 소비했다.**
  본문만 지시로 읽는다

## 1. ★ 이 폴더에 새 작업 파일을 만들지 않는다 (강제)

**`_AGENT_TASKS/todo/` 에 `.md` 를 생성·복사·이동하지 않는다.** 자기가 자기를 부르는
고리가 되고, 무인 회차에서 그것은 멈추지 않는다.

- 후속 작업이 떠오르면 **보고에 "다음에 이걸 하면 좋겠다" 로 적는다.** 사람이 읽고 만든다
- 러너가 실행 전후로 `todo/` 를 비교해 **새로 생긴 파일을 지운다** — 이 문구를 어겨도
  결과가 안 남고, 지운 사실이 작업 파일과 로그에 기록된다
- `done/` · `failed/` 도 손대지 않는다. 러너가 옮긴다

## 2. 지시를 풀어 쓴다

본문은 사람이 자유롭게 쓴 것이라 형식이 없다. 실행 가능한 단위로 분해해 **대상 볼트**의
`_STATUS.md` 로 옮긴다.

- **범위 제한을 놓치지 않는다.** `일단 ~ 에만`, `~ 는 빼고` 같은 말이 있으면 그대로 옮긴다
- 지시가 모호해 여러 갈래로 갈리면 **가장 좁은 해석**을 택하고, 넓은 해석을
  `_STATUS.md` Blocked 에 남긴다. 물어볼 사람이 없으므로 되돌리기 쉬운 쪽으로 간다

## 3. 볼트 라우팅과 작업 규칙은 평소와 같다

루트 `CLAUDE.md` (Codex 는 `AGENTS.md`) 의 볼트 진입 프로토콜, 대상 볼트 진입점,
`.agents/rules/` 를 그대로 따른다. 무인이라고 규칙이 느슨해지지 않는다.

**Codex 로 도는 회차의 추가 절차** — 훅이 없으므로 세션 진입 시 직접 호출한다:

```bash
node "Vaults/BasicVaults/CoreHub/.sync/_tools/cli-node/bin/cli.js" agents-sync --verify
```

특히 양쪽 공통:
- 노트 편집 후 `review` 로 `POST_EDIT_REVIEW_BAD=0` 확인
- 한국어 산출물은 한글 무결성 검사 (한글 존재 · 물음표 3연속 0건)

## 4. 판단이 막히면 멈춘다

무인 실행에서 가장 위험한 것은 **모르는 채로 밀어붙이는 것**이다.
다음이면 중단하고 대상 볼트 `_STATUS.md` Blocked 에 사유를 적은 뒤 종료한다.

- 사람 눈으로 봐야 갈리는 판정 (아트 후보 선별, 색·톤, "이게 나은가")
- 되돌리기 어려운 변경 (파일 대량 이동, 스키마 변경, 외부 발행)
- 지시가 기존 결정과 충돌하는데 어느 쪽이 맞는지 근거가 없을 때

**중단은 실패가 아니다.** 잘못 밀어붙인 커밋을 되돌리는 비용이 더 크다.
중단해도 **exit 0 으로 정상 종료**한다 — 작업 파일은 `done/` 으로 가고, 무엇이 막혔는지는
아래 § 5 보고에 남는다.

## 5. 마지막 — 작업 파일에 결과를 적는다

러너가 파일 끝에 실행 메타 (에이전트·모델·종료코드·로그 경로) 를 자동으로 붙인다.
**그 위에 사람이 읽을 요약을 직접 적는다.**

- 무엇을 했는지 1~3줄
- 바꾼 파일 경로 · 커밋 해시
- 중단했으면 사유와 **사람이 무엇을 정하면 풀리는지**
- 후속 제안 (§ 1 — 파일로 만들지 말고 여기 적는다)

## 6. 커밋 — 푸시는 하지 않는다

**어느 레포에도 push 하지 않는다.** 원격 반영은 사람이 한다.

커밋은 **경로를 명시해서 add** 한다. 다른 에이전트의 미커밋 변경이 트리에 남아 있을 수
있어 `git add -A` 는 그것까지 쓸어 담는다.

## 7. 되돌리기 어려운 것은 하지 않는다

`.agents/rules/custom/agent-ownership.md § 위험도 기준` 을 그대로 적용한다.

- **외부로 나감** (push · 배포 · 게시 · 전송 · 비용 발생 호출) — 무인 회차에서 금지
- **되돌리기 어려움** (대량 이동·삭제, 스키마 변경, 브랜치 재작성) — § 4 로 중단

**단 § 8 의 자기 로그 채널 보고는 여기 해당하지 않는다** (2026-09-09). 그것은 외부
발행이 아니라 **이 회차가 사람에게 결과를 돌려주는 유일한 창**이다. 이 구분이 없어
Codex 회차가 § 8 을 "전송 금지" 로 읽고 보고를 거부했고, 그래서 `#log-codex` 가
비어 있었다 (실측 2026-09-09 20:04, exit 0 인데 채널 무음). 금지 대상은 **채널 밖으로
나가는 것** — 커뮤니티 서버 게시, 외부 API 발행, 메일·DM 전송 — 이다.

**Codex 회차는 이 문구가 유일한 방어선이다.** Claude 는 `profiles/*.json` 의 deny 목록이
한 겹 더 있지만 Codex 에는 그 겹이 없다 (사용자 결정 2026-09-09, 권한을 Claude 와 동급으로).

## 8. 디스코드 보고 (강제)

작업 파일에 적은 § 5 요약을 **로그 채널에도 한 번 남긴다.** 러너가 `AIMV_LOG_CHANNEL`
을 이 회차의 에이전트 채널 (`log_claude` / `log_codex`) 로 넣어 두므로 `'log'` 만 쓰면
알아서 간다. 어느 쪽인지 고르지 마라.

`<scripts>` 는 **이 지시서가 있는 `daemon/` 의 부모 폴더**다 — 프롬프트로 받은 지시서 경로에서
`daemon/tasks/<이름>.md` 를 뗀 것. 절대경로를 박지 않는 이유는 설치 위치가 저장소마다 다르기 때문이다.

```python
import sys
sys.path.insert(0, '<scripts>/discord')
import discord_io as dio
cfg = dio.load_config()
dio.send(cfg, 'log', '...')
```

넣을 것: 작업 파일명 · 무엇을 했는지 1~3줄 · 커밋 해시 · 중단했으면 사유.
**중단했어도 보고는 한다** — 침묵과 중단은 사람 쪽에서 구별이 안 된다.
