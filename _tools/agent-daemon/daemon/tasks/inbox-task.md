# 지시서 — 인박스 항목 1건 처리 (무인 실행, 디스코드 ▶️ 트리거)

> `Run-ClaudeTask.ps1 -Task inbox-task -PermissionMode bypassPermissions` 가 부르는 지시서.
> 사람이 없는 상태에서 실행된다. **물어볼 상대가 없다는 전제로 판단한다.**

## 0. 가장 먼저 — 할 일이 없으면 아무것도 하지 않는다

**멀티볼트 루트의 `_INBOX.md`** 의 `## 대기 중` 을 읽는다 (2026-09-06 에 게임 볼트에서
루트로 올라왔다 — `#task-queue` 는 게임뿐 아니라 멀티볼트 전반·디바이스에 던지는 창구다).

**항목이 어느 볼트 일인지는 루트 `CLAUDE.md` 의 볼트 진입 프로토콜로 판정한다.**
큐가 루트에 있다고 해서 루트에서 작업하는 것이 아니다 — 대상 볼트로 들어가서 한다.

**`- [ ]` 항목이 하나도 없으면 즉시 종료한다.** 커밋도 하지 않는다.
`- [?]` (보류, § 4) 는 세지 않는다 — 사람이 풀어야 하는 항목이지 할 일이 아니다.

이 규칙이 이 시스템의 안전장치다. 참고한 사례에서 보고된 실패 모드가
**"큐가 비면 루프가 스스로 할 일을 만들어 절대 실패할 수 없는 작업만 반복하고,
며칠이 지나도 개발이 진척되지 않는 것"** 이었다. 여기서 일을 지어내면 그 상태가 된다.

**할 일을 지어내지 않는다. 방향은 항상 사람이 댄다.**

## 1. 한 번에 한 항목

**어느 항목인가** — 순서대로 본다:

1. `.vault_data/inbox_target.json` 이 있으면 그 `content` 와 본문이 같은 `- [ ]` 항목.
   사람이 디스코드에서 ▶️ 를 **그 메시지**에 눌렀다는 뜻이다 (`run_trigger.py` 가 쓴다).
   항목이 여럿일 때 누른 것과 다른 것을 처리하면 폰의 ⏳·✅ 표식이 거짓말이 된다
2. 파일이 없거나 (사람이 인박스를 손으로 고쳐) 일치하는 줄이 없으면
   `## 대기 중` 의 **가장 위 `- [ ]`** (적재가 FIFO 라 가장 오래된 것)

**항목 맨 앞 `[...]` 태그는 지시가 아니다.** `[codex:high]` 같은 것은 어느 에이전트·모델·
생각수준으로 돌지 고르는 표식이고 **러너가 이미 소비했다.** 지시를 해석할 때 무시한다.

**`- [?]` 는 건너뛴다.** 앞 회차가 § 4 로 보류한 항목이라 다시 잡아도 같은 자리에서 막힌다.

그 **하나만** 처리한다. 여러 개를 몰아 하지 않는다.

- 한 항목이 실패해도 나머지가 큐에 남는다
- 사람이 로그를 볼 때 무엇이 무엇을 바꿨는지 1:1 로 대응된다

## 2. 지시를 풀어 쓴다

인박스 항목은 폰에서 한 줄로 던진 것이라 형식이 없다. 실행 가능한 단위로 분해해
대상 볼트의 `_STATUS.md` 로 옮긴다.

- **범위 제한을 놓치지 않는다.** `일단 ~ 에만`, `~ 는 빼고` 같은 말이 있으면
  그대로 옮겨 적는다. 옮기지 않으면 다음 세션이 범위를 넓힌다
- 지시가 모호해서 여러 갈래로 갈리면 **가장 좁은 해석**을 택하고, 넓은 해석을
  `_STATUS.md` Blocked 에 남긴다. 물어볼 사람이 없으므로 되돌리기 쉬운 쪽으로 간다

## 3. 볼트 라우팅과 작업 규칙은 평소와 같다

루트 `CLAUDE.md` 의 볼트 진입 프로토콜, 대상 볼트 `CLAUDE.md`, `.claude/rules/` 를
그대로 따른다. 무인 실행이라고 규칙이 느슨해지지 않는다.

특히:
- 노트 편집 후 `review` 로 `POST_EDIT_REVIEW_BAD=0` 확인
- 한국어 산출물은 한글 무결성 검사 (한글 존재 · `\?{3,}` 0건)
- 게임 레포 (`C:/Dev_Game/Godot_Projects/GodotVamSurLike`) 는 **별도 레포**다

## 4. 판단이 막히면 멈춘다

무인 실행에서 가장 위험한 것은 **모르는 채로 밀어붙이는 것**이다.

다음이면 작업을 중단하고 `_STATUS.md` Blocked 에 사유를 적은 뒤 종료한다.

- 사람 눈으로 봐야 갈리는 판정 (아트 후보 선별, 색·톤, "이게 나은가")
- 되돌리기 어려운 변경 (파일 대량 이동, 스키마 변경, 외부 발행)
- 지시가 기존 결정과 충돌하는데 어느 쪽이 맞는지 근거가 없을 때

**중단은 실패가 아니다.** 잘못 밀어붙인 커밋을 되돌리는 비용이 더 크다.

**중단한 항목은 `- [ ]` → `- [?]` 로 바꾸고 바로 아래에 사유 한 줄을 단다** (2026-09-03).

```markdown
- [?] (YYYY-MM-DD, discord) <원문 그대로>
  → ⛔ 보류 (YYYY-MM-DD): <왜 무인이 못 하는가 · 사람이 무엇을 정하면 풀리는가>
```

`- [ ]` 그대로 두면 § 1 이 다음 ▶️ 마다 같은 항목을 다시 집어 **그 아래 항목이 영원히
안 돈다** (2026-09-02 Tripo 건이 그랬다 — 사람 세션 몫인데 큐 맨 위를 하루 점유했다).
`- [?]` 는 § 0·§ 1 이 세지 않고 viz 현황에는 "보류 N건" 으로 따로 뜬다.
**되살리는 것은 사람 몫** — `- [ ]` 로 되돌리거나 새로 던진다. 에이전트가 되돌리지 않는다.

## 5. 처리 후 인박스 갱신

끝낸 항목을 `## 대기 중` 에서 `## 처리됨` 으로 옮긴다. **지우지 않는다.**

```markdown
- [x] (YYYY-MM-DD) <원문 그대로>
  → <한 줄 결과>
  → `_STATUS.md` Now § <섹션>
```

중단했으면 **`## 대기 중` 에 `- [?]` 로 남긴다** (§ 4). `## 처리됨` 으로 옮기지 않는다 —
처리된 것이 아니다.

## 6. 커밋 — 푸시는 하지 않는다

볼트와 게임 레포는 별도로 커밋한다. **어느 레포에도 push 하지 않는다.**
원격 반영은 사람이 한다.

볼트 커밋은 **경로를 명시해서 add** 한다. 다른 에이전트(Codex)의 미커밋 변경이
트리에 남아 있을 수 있어 `git add -A` 는 그것까지 쓸어 담는다.

## 6-1. 브라우저 — 무인에서도 쓸 수 있다 (2026-09-02 추가)

대화형 세션의 `mcp__Claude_Browser__*` · `mcp__claude-in-chrome__*` 는 **호스트 앱이 주는
도구라 무인 CLI 에 안 붙는다** (실측 확인). 무인에서 쓰는 것은 `mcp__playwright__*` 다.

- 설정: 루트 `.mcp.json` — Chrome 실행파일 + **전용 프로필** `C:/Users/c/.agent-browser-profile`
- 프로필이 유지되므로 **한 번 로그인해 둔 사이트는 매번 다시 로그인하지 않는다**
- 주요 도구: `browser_navigate` · `browser_snapshot` · `browser_click` · `browser_type` ·
  `browser_take_screenshot` · `browser_evaluate`

### 전용 프로필이라는 것의 의미

사용자 메인 크롬이 **아니다.** 거기 로그인된 계정만 쓸 수 있고, 그게 의도다
(사용자 결정 2026-09-02 — 무인 에이전트에 로그인된 브라우저를 주는 것은 그 프로필로 할 수
있는 모든 것을 허용하는 것이라 계정 범위를 좁혔다).

- 로그인이 안 돼 있으면 **로그인을 시도하지 않는다.** 자격증명을 다루지 않는다
- `_STATUS.md` Blocked 에 "그 사이트 로그인 필요" 를 남기고 그 항목은 § 4 대로 `- [?]` 보류한다
- 새 사이트에 로그인이 필요하면 사람이 그 프로필로 직접 한다

### Tripo 는 어디까지 무인인가 (2026-09-03 실측 기준)

| 단계 | 무인 | 근거 |
|------|------|------|
| 이미지 생성 (`/workspace/generate-image`) | **가능** — 전용 프로필에 로그인이 있을 때 | 무료 (`Free N/100`), 크레딧 소모 없음 |
| 후보 고르기 | **불가** | 사람 눈 판정 (§ 4) |
| 3D 생성 (55크레딧) | **불가** | 아래 금지 — 크레딧 소모 버튼 |

즉 무인 회차의 Tripo 는 **이미지 4장을 뽑아 로그 채널에 올리고 `- [?]` 로 보류**하는 데까지다.
고르고 3D 로 넘기는 것은 유인 세션에서 한다.

### 금지

- **결제·구매·구독 변경** — 크레딧 소모가 걸린 버튼은 사람이 누른다
- **계정 설정 변경 · 외부 발행** (게시·전송·공개)
- 사용자 메인 크롬 프로필 (`--user-data-dir` 를 바꾸는 것) 사용

**§ 7 의 자기 로그 채널 보고는 여기 해당하지 않는다** (2026-09-09). 그것은 외부
발행이 아니라 이 회차가 사람에게 결과를 돌려주는 유일한 창이다. 이 구분이 없어
Codex 회차가 보고를 "전송 금지" 로 읽고 거부한 적이 있다 (실측, `agent-task` 쪽).

### 캡처는 보고에 싣는다

브라우저로 뭔가 확인했으면 `browser_take_screenshot` 결과를 § 7 의 `files=` 로 올린다.
사람이 폰에서 보고 다음 지시를 던지는 것이 이 시스템의 목적이다.

## 7. 마지막 — 디스코드 보고

`#log-claude` 또는 `#log-codex` 에 결과를 남긴다. 이게 사람이 폰에서 보는 유일한 창이다.

**어느 쪽인지 고르지 마라.** `'log'` 이 이 회차의 에이전트 채널로 자동으로 간다
(러너가 넣은 `AIMV_LOG_CHANNEL` 을 `discord_io.channel` 이 읽는다).

`<scripts>` 는 **이 지시서가 있는 `daemon/` 의 부모 폴더**다 — 프롬프트로 받은 지시서 경로에서
`daemon/tasks/<이름>.md` 를 뗀 것. 절대경로를 박지 않는 이유는 설치 위치가 저장소마다 다르기 때문이다.

```python
import sys
sys.path.insert(0, '<scripts>/discord')
import discord_io as dio
cfg = dio.load_config()
dio.send(cfg, 'log', '...')
```

보고에 넣을 것: 처리한 항목 원문 · 무엇을 했는지 1~3줄 · 커밋 해시 · 중단했으면 사유.

### 모델·생각수준·남은 사용량은 매번 붙인다 (2026-09-04 사용자 지시)

보고 **마지막 두 줄**에 아래 출력을 그대로 붙인다. 대화형이면 상태줄과 `/usage` 로 보는
것들이라, 폰으로 ▶️ 만 누르는 회차에서는 이 두 줄이 그것을 볼 수 있는 유일한 자리다.

```bash
python <scripts>/daemon/claude_usage.py
```

```
모델 — claude-opus-5 · 생각수준 high · CLI 2.1.235
남은 사용량 — 5시간 82% 09-05 03:10 리셋 · 주간 44% · 추가 사용량 OFF
```

- **모델 줄** — 이 회차가 실제로 어느 모델·생각수준(effort)으로 돌았는지. 모델은 세션
  트랜스크립트의 assistant 항목에서, 생각수준은 env `CLAUDE_EFFORT` 에서 읽는다.
  래퍼가 모델을 지정하지 않으므로 (CLI 기본값을 쓴다) **설정 파일을 봐도 알 수 없다** —
  회차마다 달라질 수 있고, 그래서 매회 찍는다
- **사용량 줄** — `/usage` 와 같은 엔드포인트의 **남은** 비율·리셋 시각·추가 사용량 on/off

둘 중 어느 쪽이든 못 읽으면 "알 수 없음" · "조회 실패" 한 줄이 나올 뿐이니
**그 줄도 그대로 싣는다** — 보고를 멈추지 않는다.

산출물이 **눈으로 봐야 하는 것**이면 (렌더, 타일, 스크린샷) `files=` 로 같이 올린다.
사람이 폰에서 보고 다음 지시를 던질 수 있게 하는 것이 이 시스템의 목적이다.
