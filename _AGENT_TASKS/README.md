# _AGENT_TASKS — 사람이 던지면 CLI 가 실제로 도는 큐

> 2026-09-09 신설. **볼트 아님** — `_AGENT_COMMS/` 와 같은 런타임 폴더.
> 배포 미대상.

## `_AGENT_COMMS/` 와 무엇이 다른가

| | `_AGENT_COMMS/` | **`_AGENT_TASKS/`** |
|---|---|---|
| 무엇 | 에이전트 **끼리 주고받는 메시지** | 사람이 던지는 **실행 요청** |
| 누가 읽나 | 다음 세션의 에이전트가 읽고 판단 | **러너가 읽고 CLI 를 띄운다** |
| 실행 | 사용자가 "처리해" 해야 시작 | 러너를 돌리면 그 자리에서 실행 |

즉 COMMS 는 "이거 봐 둬", TASKS 는 "이거 해".

## 폴더

```
_AGENT_TASKS/
├── README.md      이 파일
├── todo/          실행 대기 — 여기에 .md 를 넣는다
├── done/          성공 (exit 0)
└── failed/        실패
```

## 작업 파일 형식

`todo/` 에 `.md` 하나 = 작업 하나. **사람이 직접 만들어도 되고 AI 가 만들어도 된다.**

```markdown
---
type: agent-task
agent: codex
model: gpt-6-astra
effort: high
created: 2026-09-09T14:00:00
---

# 짧은 제목

여기에 지시를 자유롭게 쓴다. 길어도 된다 — 그게 이 폴더의 존재 이유다.
디스코드 인박스는 한 줄짜리고, 여기는 문단·표·코드블록을 다 쓸 수 있다.
```

`agent` · `model` · `effort` 는 **frontmatter 로만** 준다. 본문에 적어도 안 읽는다.

### 모델·생각수준을 고르는 이유

같은 지시라도 무게가 다르다. 단순 정리는 `haiku`/`low`, 설계 판단은 `opus`/`xhigh`.
**생략이 기본**이고, 생략하면 각 CLI 의 기본값으로 간다.

## 실행

```bash
python <scripts>/daemon/run_agent_tasks.py
# <scripts> = Run-AgentTask.ps1 이 있는 daemon/ 의 부모 폴더 (배포본: _tools/agent-daemon)
```

| 옵션 | 동작 |
|------|------|
| (없음) | `todo/` 를 **파일명 순서대로 전부** 처리 |
| `--one` | 맨 앞 하나만 |
| `--dry-run` | 무엇이 어떤 에이전트·모델로 돌지만 출력. 실행 안 함 |
| `--file <경로>` | 그 파일 하나만 |

**스케줄러에 걸려 있지 않다.** 사람이 돌릴 때만 돈다 — 폴더에 파일을 떨어뜨리는 것만으로
무인 실행이 시작되지 않는다. 자동화가 필요하면 그때 별도로 결정한다.

## ★ 재귀 금지 (강제)

**이 폴더의 작업이 이 폴더에 새 작업 파일을 만들 수 없다.** 만들면 자기가 자기를 부르는
고리가 되고, 무인 회차에서 그건 멈추지 않는다.

강제 방법은 두 겹이다.

1. 각 작업의 프롬프트에 금지 문구가 들어간다 (러너가 붙인다)
2. **러너가 실행 전후로 `todo/` 를 비교한다.** 새로 생긴 `.md` 는 **지우고 로그에 남긴다** —
   에이전트가 문구를 무시해도 결과가 남지 않는다

후속 작업이 필요하면 **작업 보고에 "다음에 이걸 하면 좋겠다" 로 적는다.** 사람이 읽고
새 파일을 만든다. 판단을 사람에게 돌려주는 것이 이 규칙의 목적이다.

## 결과

| 끝난 상태 | 어디로 | 무엇이 남나 |
|----------|--------|-----------|
| exit 0 | `done/` | 원본 + 실행 결과 요약이 파일 끝에 붙는다 |
| exit ≠ 0 | `failed/` | 위와 같음. 고쳐서 `todo/` 로 되돌리면 다시 돈다 |

로그 전문은 `.vault_data/logs/agent-task_*.log`.

## 주의

- **작업 파일에 자격증명·토큰을 적지 않는다.** 이 폴더는 git 추적된다
- 되돌리기 어려운 것 (대량 삭제·스키마 변경·외부 게시·비용 발생) 은 여기 던지지 않는다 —
  `.agents/rules/custom/agent-ownership.md § 위험도 기준`
- `done/` 을 지우지 않는다. 왜 그렇게 했는지의 근거가 사라진다
